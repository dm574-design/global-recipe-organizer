# Global Recipe Organizer

## Overview

The Global Recipe Organizer is a PHP and MySQL web application developed using the Model-View-Controller (MVC) architecture.

This application allows users to manage recipes, ingredients, and cooking instructions through a user-friendly web interface.

## Features

* Create, Read, Update, and Delete Recipes
* Ingredient Management Module
* Instruction Management Module
* Search Recipes by Name
* PDO Database Connectivity
* MVC Design Pattern Implementation
* Relational Database Structure

## Technologies Used
